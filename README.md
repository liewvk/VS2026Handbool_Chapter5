# VS2026 Handbook - Chapter 5

This repository contains Python examples from Chapter 5 of the VS2026 handbook. The examples demonstrate lists, dictionaries, list comprehensions, conditional expressions, and basic data aggregation and reporting.

## Prerequisites

- Python 3
- Visual Studio 2026 or Visual Studio Code (optional)

## Running the examples

Open a terminal in the repository directory and run any example:

```bash
python example5.5.py
python scores.py
```

You can also run a Python file directly from Visual Studio using the project file `VS2026Handbool_Chapter5.pyproj`.
